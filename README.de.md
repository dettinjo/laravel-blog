# Laravel Blog

Eine vollständige Blogging-Plattform, entwickelt mit dem PHP-Framework Laravel. Das Projekt demonstriert Backend-Entwicklung mit MVC-Architektur, Datenbankmigrationen und Blade-Templating.

<p align="center">
  <img src="docs/laravel.svg" alt="Laravel" width="170" />
</p>

### Funktionen

- **Artikel-Management** mit Erstellen, Bearbeiten und Löschen von Beiträgen
- **Benutzerauthentifizierung** mit Laravel Breeze
- **Kommentarsystem** für Leserfeedback
- **Blade-Templates** für serverseitiges Rendering
- **MySQL-Datenbank** mit Eloquent ORM
- **MVC-Architektur** für klare Code-Strukturierung

### Technischer Aufbau

Das Projekt nutzt Laravels Routing- und Middleware-System für Authentifizierung und Autorisierung. Datenbankmigrationen ermöglichen eine versionierte Schemaentwicklung, während Eloquent ORM den Datenbankzugriff vereinfacht.
